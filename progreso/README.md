# 📊 Seguimiento de Progreso

Este directorio contiene el tracking de tu aprendizaje.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `tracker.json` | Estado detallado de cada módulo y ejercicio |
| `errores-comunes.md` | Bitácora de errores para aprender de ellos |
| `estadisticas.html` | Dashboard visual de progreso (abrir en navegador) |

## Cómo se actualiza

1. Completas un ejercicio → actualizo `tracker.json`
2. Documentas un error → lo agregas a `errores-comunes.md`
3. Avanzas de módulo → actualizo porcentaje global

## Dashboard Visual

Abre `estadisticas.html` en tu navegador para ver:

- 🟢 Barra de progreso global
- 📊 Gráfico de módulos completados vs pendientes
- 📈 Racha de días de estudio
- ❌ Errores más frecuentes
